# 📉 Market Surface Predictor

Synthetic Financial Data • Polynomial Regression • 3D Visualization
A lightweight AI + quant project that generates synthetic financial data and models price behavior as a 3D surface over time and volatility.

🧠 Overview

Market Surface Predictor demonstrates how machine learning can approximate relationships in financial systems — using fully simulated data.
It builds a smooth surface where:
⏱️ Time
🌪️ Volatility
💰 Price
are mathematically connected and visualized in 3D space.

⚙️ Features
🎲 Synthetic financial dataset generation
🤖 Polynomial regression modeling
📊 3D surface plot with contour projections
⚡ Fast and CPU-friendly execution
🧪 No external datasets required
