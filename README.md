# 🚀 QuantAI-Lab-AI-Quantitative-Modeling-Playground
A curated collection of lightweight Python projects blending Artificial Intelligence, Quantitative Finance, and Data Visualization using fully synthetic datasets.
Designed for learning, experimentation, and portfolio building.

# 🧠 Overview

QuantAI Lab showcases three self-contained projects that simulate real-world problems in finance and urban analytics — without requiring real datasets.

Each project focuses on:

📊 Data simulation
🤖 Machine learning models
📈 Visual insights

# 📦 Projects
📉 1. Market Surface Predictor

🔍 Description
Simulates financial market behavior and visualizes price movements as a 3D surface based on time and volatility using regression models.

⚙️ Features

Synthetic market data generation
Polynomial regression modeling
3D surface visualization

📚 Concepts

Financial Markets
Volatility Modeling
Polynomial Regression
3D Plotting

⚠️ Disclaimer
For educational purposes only — not for real financial predictions.

# 📊 2. Smart Backtesting Engine

🔍 Description
Implements a simulated trading system using synthetic stock data and ML-driven signals to evaluate performance.

⚙️ Features

Random walk price simulation
Strategy backtesting
Equity curve visualization
Drawdown analysis


📚 Concepts

Backtesting Systems
Moving Averages
Strategy Evaluation
Risk Metrics

⚠️ Disclaimer
Not intended for live trading or financial advice.

# 🏙️ 3. Urban Data Modeling with AI

🔍 Description
Explores relationships between distance, population density, and housing prices using machine learning and advanced visualizations.

⚙️ Features

Synthetic urban dataset
Regression modeling
Heatmaps & 3D plots
Smooth curve fitting


📚 Concepts

Urban Analytics
Regression Models
Data Visualization
Spatial Relationships

⚠️ Disclaimer
For educational and research use only.

💡 Key Highlights
🧪 100% Synthetic Data (No external datasets required)
⚡ Lightweight & CPU-friendly
🎯 Beginner to Intermediate Friendly
🛠️ Focused on core AI + Quant concepts
